
# SwiftMart – E-Commerce Web App

SwiftMart is a fully functional and responsive E-Commerce web application built using **React.js** for the frontend and **Node.js** for the backend. It supports Razorpay payment integration for secure transactions.



## Demo

https://swift-mart-ecommerce.netlify.app/


## Features

- Product Listing Page with Filters
- Add to Cart / Wishlist
- User Address Form & Checkout
- Razorpay Payment Gateway Integration
- Persistent Cart/Orders with LocalStorage
- Order Summary & Payment Confirmation (Test Mode)
- Responsive design
- Smooth UI using ReactJS & Responsive Design


## Tech Stack

### Frontend:
- ⚛️ ReactJS
- 🧾 React Router DOM
- 🎨 React Icons

### Backend:
- Node.js

## Installation & Setup

Prerequisites

- Node.js installed
- Git installed

Clone the project

```bash
  git clone https://github.com/dhgo21/Ecommerce-project
```

Go to the project directory

```bash
  cd SwiftMart
```

Setup Frontend

```bash
  cd frontend  
  npm install  
  npm run dev
```

Setup Backend

```bash
  cd backend  
  npm install  
  npm run start
```
Make sure to configure your Razorpay KEY_ID and KEY_SECRET in .env
